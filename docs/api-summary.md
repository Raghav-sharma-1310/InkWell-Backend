# API Summary

Detailed service endpoints are exposed through Swagger for each service under `/swagger-ui.html` and `/v3/api-docs`.

## Gateway Route Prefixes

- `/api/auth/**`
- `/api/posts/**`
- `/api/comments/**`
- `/api/categories/**`
- `/api/media/**`
- `/api/newsletter/**`
- `/api/notifications/**`

## Useful Demo Endpoints

- `POST /api/auth/login`
- `GET /api/posts/public`
- `GET /api/posts/public/{slug}`
- `POST /api/comments`
- `POST /api/newsletter/public/subscribe`
- `GET /api/notifications`
